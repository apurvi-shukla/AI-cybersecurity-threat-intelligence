# AI Cybersecurity Threat Intelligence System

This project uses Machine Learning and Natural Language Processing (NLP) to detect potential phishing emails based on their text content.

## Features
- Phishing Email Detection
- Text Preprocessing and TF-IDF Vectorization
- Machine Learning Classification
- Interactive Streamlit Web Application

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- NLP (TF-IDF)
- Streamlit

## Machine Learning Models
- Logistic Regression
- Multinomial Naive Bayes
- Linear SVC

## Model Accuracy
- Logistic Regression: 98.26%
- Naive Bayes: 96.05%
- Linear SVC: 98.79%
